# 开源方向性策略评测（2026-10-22）

> 只回测，不下单，不碰线上机器人。分支 `claude/modest-wiles-efab49`。复现：
>
> ```bash
> .venv/bin/python tools/oss_eval.py fetch      # data.binance.vision 下载 Binance 永续 1h K 线 + 资金费（约 18 MB）
> .venv/bin/python tools/oss_eval.py run        # 60 个 walk-forward 任务，4 进程约 5 分钟
> .venv/bin/python tools/oss_eval.py report     # 生成下面“完整结果”里的表格
> ```

## 结论

1. **没有一个候选比现在线上的均线 20/50 + ADX≥20（4h）更好，不建议换策略，也不建议加进组合。**
   按“两个窗口样本外都为正”的规则，10 个“策略×周期”里有 6 个算“有效”，全部是突破 / 趋势类（`bb_breakout`、`dual_thrust`、`vol_system`）；但同一样本外区间里，线上均线 4h 的等权夏普是 **0.90 / 0.96**（2021 起 / 2023 起），候选里只有 `bb_breakout` 4h 在 2021 窗口更高（1.26），2023 窗口反而更低（0.87）；其余都更低或两个窗口一高一低。
2. **能赚钱的都是趋势 / 突破，和线上策略是同一个赌注。** 6 个“有效”配置跟均线 4h 的日收益相关性 0.38~0.73；和均线各半组合后，夏普要么两个窗口都变差，要么一升一降（例如 `bb_breakout` 4h：1.11 / 0.93 vs 均线单独 0.90 / 0.96），没有一个在两个窗口里都提高。
3. **均值回归两条（`rsi2`、`bb_reversion`）在 4h 和 1h、两个窗口全部为负**，1h 的 `bb_reversion` 样本外 −53% / −40%。和线上策略低相关（−0.35~0.15），但本身是亏的，组合后夏普全部变差。按 taker 0.05% + 滑点 0.05% 的成本，短线反转吃不下来；这和之前“缩短周期”被否掉的结论一致。
4. **“波动率收缩后突破”没被选中。** `bb_breakout` 的网格里带了 squeeze 条件（带宽处在近 120 根的最低 10%/25% 分位），walk-forward 大多数窗口选的是“不加 squeeze、加 Ichimoku 云过滤”（也就是 jesse SimpleBollinger 原版），squeeze 版本只在少数窗口被选中。
5. **顺带修了一个引擎 bug，影响此前所有带资金费的 walk-forward 数字。** `funding_per_bar` 会把切片最后一根 K 线之后的全部资金费都记到最后一根上；walk-forward 给每个训练 / 测试切片传的是完整资金费表，于是每个窗口末尾的持仓被记上之后几年的资金费，训练期选参也因此“看到了未来”。修复见提交 2c33eb5（加了两个回归测试）。
   复核：HANDOVER 里“`walkforward --since 2023-01-01 --market perp --timeframe 4h` 滚动选参 +36.06%”用旧代码在本次数据上**精确复现**，修复后是 **+25.96%**；固定 20-50 那列（整段一次回测）不受影响。所以“滚动选参不如固定参数”这个结论反而更强了。本文所有数字都是修复后的。

## 评测口径（跑之前定死）

| 项 | 设置 |
| --- | --- |
| 市场 | Binance USDT 永续 BTC / ETH / SOL，4h 和 1h（4h 由 1h 聚合） |
| 窗口 | 数据从 2021-01-01 起 / 从 2023-01-01 起，都截到 2026-10-22 00:00 UTC；第一年只用来训练，所以样本外分别是 2022-01-01 ~ 2026-10-21 和 2024-01-01 ~ 2026-10-21 |
| 成本 | taker 0.05% / 边，滑点 0.05% / 边（`config.example.yaml` 现值），按历史资金费逐期结算 |
| 仓位 / 风控 | 同 `config.example.yaml`：每笔风险 1%，止损 2×ATR(14)，1 倍杠杆上限；**关掉 20% 回撤熔断和 3% 日亏损停手**（同 `experiments/compare_filters.py`，避免熔断把后半段冻结成空仓） |
| 选参 | `bot/engine/optimize.py::walk_forward`：训练 365 天、测试 90 天、滚动；训练期夏普最高且 ≥ 5 笔的参数用于下一个测试窗口；只统计拼起来的测试窗口 |
| 网格 | 每个策略类的 `param_grid`，写死在代码里，跑之前定好：rsi2 24 组、bb_reversion 18 组、bb_breakout 24 组、dual_thrust 16 组、vol_system 15 组，合计 97 组 |
| 组合 | BTC/ETH/SOL 各分 1/3 资金、各自复利（同 `tools/portfolio_backtest.py` 的等权思路） |
| 对照 | BTC 买入持有、三币等权买入持有、线上均线 20/50 + ADX≥20（固定参数，同一样本外区间） |
| 有效 | 等权组合在两个窗口的样本外收益都为正 |

试了多少组：walk-forward 一共做了 60 次（5 策略 × 3 币 × 2 周期 × 2 窗口），训练期回测 **18,624 次**，另有 1,164 次“事后最优”对照回测（不参与选参）。10 个“策略×周期”配置里挑最好的，本身就有多重比较的偏差，排名靠前的数字要打折看。

另外要注意：**两个窗口不是独立样本**，2023 窗口的样本外（2024-01 起）完全包含在 2021 窗口的样本外里，只是训练起点不同。真正独立的检验是 2021 窗口里 2022~2023 那段，见“按年拆开”表。

## 候选策略：出处、机制、和原版的差别

全部是按策略逻辑重写（`bot/strategies/` 下），没有拷贝源码。freqtrade-strategies 是 GPL-3.0，jesse example-strategies 是 MIT，hummingbot 是 Apache-2.0。

| 策略（代码名） | 出处 | 机制 | 本仓库实现和原版的差别 |
| --- | --- | --- | --- |
| `rsi2` | jesse [example-strategies/RSI2](https://github.com/jesse-ai/example-strategies/tree/master/RSI2)（Larry Connors RSI(2)） | **趋势内回调的均值回归**：收盘在 200 均线上方且 RSI(2) ≤ 10 做多，收盘回到 5 均线上方平仓；空头对称 | 原版满仓、无止损；这里用统一的 1% 风险 + 2×ATR 止损。网格扫 RSI 周期 2/3、阈值 5/10/20、趋势均线 100/200、离场均线 5/10 |
| `bb_reversion` | hummingbot [controllers/directional_trading/bollinger_v1](https://github.com/hummingbot/hummingbot/blob/master/controllers/directional_trading/bollinger_v1.py)（freqtrade `BbandRsi` 同类） | **无趋势过滤的布林带反转**：%B < 0（收盘跌破下轨）做多，%B > 1 做空 | hummingbot 靠执行器的止损 / 止盈 / 时间三重屏障离场，这里改成 %B 回到 0.5（或 0.8）平仓 + ATR 止损。网格扫周期 20/50/100、标准差 1.5/2/2.5、离场 %B 0.5/0.8 |
| `bb_breakout` | jesse [example-strategies/SimpleBollinger](https://github.com/jesse-ai/example-strategies/tree/master/SimpleBollinger) | **布林带突破 + 可选的波动率收缩条件**：收盘（hl2 布林带）突破上轨且在 Ichimoku 云上方做多，跌回中轨平仓 | 原版只做多，这里空头对称；加了 squeeze 选项（最近 10 根内带宽曾处于近 120 根的最低 `squeeze_pct` 分位，1.0 = 关）。网格扫周期 20/40、标准差 2/2.5、云过滤开/关、squeeze 1.0/0.25/0.1 |
| `dual_thrust` | jesse [example-strategies/DUAL_THRUST](https://github.com/jesse-ai/example-strategies/tree/master/DUAL_THRUST)（Michael Chalek） | **开盘价 ± 区间突破，反手**：Range = max(HH−LC, HC−LL)（前 N 根），收盘高于“锚定周期开盘价 + k×Range”做多，低于“开盘价 − k×Range”做空，反向信号时直接反手 | 锚定周期按 jesse 规则：1h → 4h、4h → 日线（UTC）。原版多空用两组参数（0.71 / 0.67），这里 k 对称。Range 只用当前 K 线之前的 N 根。网格扫 N 6/12/21/42、k 0.3/0.5/0.7/1.0 |
| `vol_system` | freqtrade-strategies [futures/VolatilitySystem](https://github.com/freqtrade/freqtrade-strategies/blob/main/user_data/strategies/futures/VolatilitySystem.py)（TradingView “Volatility System”） | **单次大波动冲击后的动量**：`change_bars` 根内收盘涨幅超过 `atr_mult`×上一根 ATR 做多，跌幅超过做空，反向信号反手 | 原版把 1h 重采样成 3h、ATR×2、出现第二次同向信号时加仓；这里直接在交易周期上算、不加仓（避开“无止损加仓”）。网格扫 ATR 倍数 1/1.5/2/2.5/3、变动根数 1/3/6 |

挑选时看过但没选的：freqtrade `Supertrend` / hummingbot `supertrend_v1`（ATR 跟踪趋势，和线上均线是同一机制）、`macd_bb_v1`（指标堆砌）、`dman_v3` / `bollingrid`（DCA / 网格加仓）、freqtrade `TDSequentialStrategy`（衰竭计数，和两条均值回归重叠）、各种 `Strategy00x` / `BinHV`（多指标叠加、短周期 scalp）。

## 数据

- 来源：[data.binance.vision](https://data.binance.vision/)（Binance 官方公开批量数据，和 API 同一份 K 线；开发机访问 API 是 451，没用代理）。1h 月度 / 日度 K 线 2021-01-01 ~ 2026-10-21 23:00；资金费月度文件到 2026-09，10 月 1~21 日用另一个研究分支从东京服务器 API 拉的 Binance 资金费补齐（同一份数据，按分钟去重）。
- 核对：聚合出来的 4h 和 API 拉的 4h（组合层研究分支的缓存）比，5 年里只有 2 根 K 线的开 / 收盘价不同（2023-11-10 12:00、2024-10-28 20:00，Binance 那两个时段的 1h 文件本身有缺口）；资金费逐条一致。SOL 1h 有两处缺口（2022-02-26 起 73 小时、2022-04-01 起 49 小时），回测直接跨过。
- 数据在 `data/`（gitignore），结果在 `reports/oss_eval/`（gitignore）。

## 怎么读这些数字

- **walk-forward 选参在这几个策略上普遍拖后腿。** 对照“默认参数固定不动”那一列：`dual_thrust` 1h 默认参数（N=21、k=0.7）BTC / ETH / SOL 是 +110% / +76% / +296%，滚动选参只有 +49% / −33% / +93%；`vol_system` 1h、`bb_breakout` 4h 的 BTC 也是同样情况。但默认参数是开源作者事后挑的，我们现在看到它好，再拿它当成绩就是事后挑选，所以排名只用滚动选参的成绩。这一点和线上均线“固定 20-50 比滚动选参稳”的结论一致。
- **单币差异很大。** `vol_system` 1h 在 BTC 上两个窗口都亏（−21% / −19%），收益全靠 ETH / SOL；`dual_thrust` 4h 2021 窗口几乎全靠 SOL（+153%）。等权组合看着“有效”，但拆开后单币稳定性不如线上均线。
- **1h 成本很重。** 三个突破类策略的 1h 版本，2021 窗口（4.8 年）手续费占总资金 24%~50%，4h 版本 7%~12%。
- **按年看**，2021 窗口里只有 `bb_breakout` 4h 和线上均线一样每年都为正；其余“有效”策略都有亏损年份。
